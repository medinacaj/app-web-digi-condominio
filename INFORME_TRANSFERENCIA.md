## Evidencia y alcance

Repositorio con README inicial mínimo. Material de continuidad nuevo, marcado como generado/propuesto y sujeto a revisión. No se transfiere el PDF privado de origen, otros proyectos, tokens, configuraciones de hosting, contraseñas ni información real de residentes. El PDF y el historial conversacional no son dependencias indispensables para retomar gracias al resumen de contexto, pero para auditoría documental exhaustiva los originales deben recuperarse por canales autorizados.

## Verificaciones

- **Realizado:** lectura de README, inventario raíz, privacidad, rama, historial, búsqueda de issues/PRs y consulta de rulesets.
- **Pendiente tras aplicar la propuesta:** comprobar que todos los archivos existen en la rama y que PR/issue links son accesibles.
- **No aplicable aún:** compilación, QA funcional, test de carga, pentest, comprobación de backup o despliegue: no hay aplicación.
- **Limitado:** configuración detallada de seguridad del repositorio y accesos; rulesets no consultables por API con plan/permiso actual.

## Clasificación

**Contexto inicial reconstruido parcialmente y disponible para revisión**, no transferencia completa de activos ni software operativo.

## Recuperación

Clonar desde la cuenta autorizada, leer `README_INICIAR_AQUI.md`, comprobar el estado de `main` y ramas; revisar `ESTADO_ACTUAL.md` y los issues. Las conexiones externas y servicios requieren permisos propios.
