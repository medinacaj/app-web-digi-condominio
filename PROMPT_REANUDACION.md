# Protocolo de reanudación de Digi-Condominio

Trabaja con el repositorio privado `medinacaj/app-web-digi-condominio`; verifica que sigues teniendo acceso. No asumas acceso a chats o archivos externos.

1. Inspecciona rama principal, PRs e issues actuales y contrasta estado con `ESTADO_ACTUAL.md`.
2. Lee `README_INICIAR_AQUI.md`, `CONTEXTO_MAESTRO.md`, `DECISIONES_Y_CAMBIOS.md`, `docs/AUDITORIA_INICIAL.md` y `docs/BACKLOG_MVP.md`.
3. Distingue fuente verificada de propuesta; no inventes código, pruebas, despliegues ni aprobaciones.
4. Conserva privacidad del repositorio y propiedad intelectual. No publiques código ni agregues accesos sin autorización.
5. Continúa desde la acción real pendiente y registra cambios mediante issue, rama, PR, prueba y actualización de estado.
6. Cierra tareas solo con evidencia, y mantén un único historial coherente en GitHub.
7. Antes de programar lógica jurisdiccional, confirma país inicial, reglas, modelo financiero y alcance aprobado.

Siguiente paso del paquete inicial: evaluar PR de documentación, revisar backlog y decidir MVP/arquitectura. Esta nota no reemplaza la inspección de GitHub en tiempo real.
